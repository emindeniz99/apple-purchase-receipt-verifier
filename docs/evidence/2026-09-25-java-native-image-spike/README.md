# Java verifier as a native shared library: spike sources, 2026-09-25

Throwaway code behind
[../2026-09-25-java-native-image.md](../2026-09-25-java-native-image.md).
It asks one question: can the unchanged Java verifier (`java/`, Bouncy
Castle 1.86, Jackson 2.22.2) be compiled by GraalVM Native Image into a
JVM-free `.so` with a C ABI, and serve as the shared core instead of the
Rust crate planned in [docs/rust-core/](../../rust-core/README.md)?

CI builds none of it. Nothing under `java/`, `rust/`, `fixtures/` or
`certs/` was changed. `$REPO` is the repository root. `$SCRATCH` is any
scratch directory outside the repository: every build output, download and
result goes there. Paths below are relative to this folder.

## Files

| Path | What it is |
|---|---|
| `bridge/src/aprvj/Bridge.java` | Plain Java 8, no GraalVM types. Options JSON in, `(code, json)` out. The same class runs on the JVM (oracle) and in the image, so a difference between the two is the image's, not the adapter's. |
| `bridge/src/aprvj/OracleCli.java` | Runs a request corpus through `Bridge` on a JVM. One JSON line out per request. |
| `native/src/aprvj/nativeimage/NativeEntryPoints.java` | The C ABI: `@CEntryPoint` shims only. Every body catches `Throwable`. |
| `config/base.json` | The 28 reflection entries and 5 resource globs that are not Bouncy Castle (Jackson payload models, `sun.security` X.509, the three Apple root `.cer` files, time-zone data). Copied from the tracing agent's output. |
| `config/minimal/reachability-metadata.json` | The metadata the build uses. Generated by `MetadataGen` from `base.json` and Bouncy Castle's own tables. Do not edit by hand. |
| `config/traced/reachability-metadata.json` | The tracing agent's merged output from three runs (cases, hostile, self-check). Kept to show why it is not enough (see the evidence note, section 4). |
| `gen/src/aprvj/gen/MetadataGen.java` | Writes `config/minimal` deterministically. |
| `gen/src/io/.../AlgorithmCorpus.java` | Generates 22 receipts and JWS signed with algorithms the fixtures do not use. Compiled against the repository's test classes (`TestPki`). |
| `build.sh` | Builds the repository jar from a copy of `java/`, the bridge, the shims, then the `.so`. |
| `c/harness.c` | C smoke test, ABI misuse checks, crash hazards, benchmark and leak loop. Builds against either the native image or the Rust C ABI (`rust/ffi`). |
| `c/pgo_train.c` | The failed attempt to train PGO through the shared library itself (no profile option exists there). Kept as evidence. |
| `bench/src/aprvj/bench/JvmBench.java` | The JVM side of the benchmark: the same inputs and measurements as `c/harness.c`. Also the PGO training executable. |
| `web/src/aprvj/web/WebMain.java` | Web Image probe: the same Bridge calls from `main`. |
| `py/aprvj.py` | ctypes binding for the image's C ABI. |
| `py/requests_gen.py` | Writes the request corpora: `cases` (from `fixtures/cases.json`) and `hostile` (seeded mutations). |
| `py/run_native.py`, `py/run_rust.py` | Run a corpus through the image, or through `rust/ffi` (using `rust/ffi/tests/conformance.py`'s own ctypes declarations). |
| `py/check.py` | `expect`: every case's expected verdict and fields. `diff`: two result files, row by row. |
| `py/compare_rust.py`, `py/explain.py` | Tally and explain Java against Rust differences. |
| `py/timev.py` | Stand-in for `/usr/bin/time -v` (wall clock and peak RSS of the children). |
| `results/` | Raw outputs quoted in the evidence note: conformance and differential tallies, Java against Rust with explanations, benchmarks (`bench-*.jsonl`), leak loops, valgrind and ASan, hazards, the negative control, dependencies, strace, sizes, reproducibility, musl, CE, PGO, Leyden and Web Image. |

## Reproduce

Linux x86_64, Oracle GraalVM 25.4.4.1.1 (JDK 25.0.4.1.1), Maven,
Python 3, gcc. One native-image build needs about 3.4 GB of RAM and 3 minutes
on 4 vCPUs.

```sh
export REPO=... SCRATCH=... GRAALVM_HOME=$SCRATCH/graalvm
G=$GRAALVM_HOME; unset JAVA_TOOL_OPTIONS

# 1. The shared library (also builds the repository jar and the bridge)
./build.sh                       # -> $SCRATCH/out/libapple_purchase_receipt_verifier_java/
CP=$(cat $SCRATCH/build/cp.txt)
OUT=$SCRATCH/out/libapple_purchase_receipt_verifier_java

# 2. Request corpora
python3 py/requests_gen.py $REPO/fixtures cases   > $SCRATCH/run/cases.jsonl
python3 py/requests_gen.py $REPO/fixtures hostile > $SCRATCH/run/hostile.jsonl
javac -cp "$CP:$SCRATCH/java-src/target/test-classes" -d $SCRATCH/build/gen \
  gen/src/io/github/emindeniz99/applepurchasereceiptverifier/AlgorithmCorpus.java
java -cp "$CP:$SCRATCH/java-src/target/test-classes:$SCRATCH/build/gen" \
  io.github.emindeniz99.applepurchasereceiptverifier.AlgorithmCorpus > $SCRATCH/run/algorithms.jsonl

# 3. Conformance through the C ABI, then the JVM oracle, then the diff
python3 py/run_native.py $OUT/libapple_purchase_receipt_verifier_java.so $SCRATCH/run/cases.jsonl > ni-cases.jsonl
python3 py/check.py expect $SCRATCH/run/cases.jsonl ni-cases.jsonl
$G/bin/java -cp "$CP" aprvj.OracleCli $SCRATCH/run/cases.jsonl > jvm25-cases.jsonl   # also Temurin 8
python3 py/check.py diff jvm25-cases.jsonl ni-cases.jsonl $SCRATCH/run/cases.jsonl
#    same for hostile and algorithms; Rust: py/run_rust.py $REPO <dir of the Rust .so> <corpus>

# 4. Regenerating the metadata (optional)
$G/bin/java -agentlib:native-image-agent=config-output-dir=$SCRATCH/agent/cases -cp "$CP" \
  aprvj.OracleCli $SCRATCH/run/cases.jsonl > /dev/null         # also hostile, and a self-check
$G/bin/native-image-configure generate --input-dir=$SCRATCH/agent/cases ... --output-dir=config/traced
javac -cp "$CP" -d $SCRATCH/build/gen2 gen/src/aprvj/gen/MetadataGen.java
java -cp "$CP:$SCRATCH/build/gen2" aprvj.gen.MetadataGen config/base.json config/minimal/reachability-metadata.json

# 5. Negative control: the same build with AppleRootCA-G2.cer left out of the resources
./build.sh $SCRATCH/config-noG2 libaprvj_negative_no_g2

# 6. C harness: smoke, hazards, benchmark, leak loop
gcc -O2 -DUSE_NI -I$OUT c/harness.c -L$OUT -lapple_purchase_receipt_verifier_java \
  -Wl,-rpath,$OUT -lpthread -o $SCRATCH/h-ni
gcc -O2 -DUSE_RUST -I$REPO/rust/ffi/include c/harness.c -L<rust release dir> \
  -lapple_purchase_receipt_verifier_ffi -Wl,-rpath,<rust release dir> -lpthread -o $SCRATCH/h-rust
F=$REPO/fixtures; IN="$F/public-receipts/receipt-sandbox-g5.b64 $F/generated/transaction.jws $F/generated/jws-root.der"
env -i $SCRATCH/h-ni smoke $IN          # no JAVA_HOME, no PATH
env -i $SCRATCH/h-ni hazards $IN
env -i $SCRATCH/h-ni bench $IN receipt 4 8
env -i $SCRATCH/h-ni leak $IN 20000
env -i $SCRATCH/h-ni startup 500
env -i SHARED=1 $SCRATCH/h-ni bench $IN receipt 16 8   # all threads share one set of handles

# 7. JVM benchmark (JDK 8 and JDK 25)
javac --release 8 -cp "$CP" -d $SCRATCH/bench-classes bench/src/aprvj/bench/JvmBench.java
java -cp "$CP:$SCRATCH/bench-classes" aprvj.bench.JvmBench $REPO/fixtures receipt 4 8 10
```

```sh
# 8. PGO (Oracle GraalVM only): train an executable, reuse its profiles for --shared
jar --create --file $SCRATCH/bench.jar -C $SCRATCH/bench-classes .
native-image --pgo-instrument -march=compatibility -cp "$CP:$SCRATCH/bench.jar" \
  -H:ConfigurationFileDirectories=config/minimal -o $SCRATCH/jvmbench-instr aprvj.bench.JvmBench
for op in receipt jws endpoint; do
  $SCRATCH/jvmbench-instr -XX:ProfilesDumpFile=$SCRATCH/$op.iprof $REPO/fixtures $op 1 2 5
done
EXTRA_NI_FLAGS="--pgo=$SCRATCH/receipt.iprof,$SCRATCH/jws.iprof,$SCRATCH/endpoint.iprof" ./build.sh config/minimal libaprvj_pgo

# 9. musl: needs a zlib built with musl-gcc -fPIC (static) in <dir>
EXTRA_NI_FLAGS="--libc=musl -H:NativeLinkerOption=-L<dir>" ./build.sh config/minimal libaprvj_musl
musl-gcc -O2 -DUSE_NI -I$OUT c/harness.c -L<musl out> -l:libaprvj_musl.so -Wl,-rpath,<musl out> -lpthread -o h-ni-musl

# 10. Web Image (experimental): binaryen's wasm-as on PATH
javac --release 8 -cp "$CP" -d $SCRATCH/web-classes web/src/aprvj/web/WebMain.java
native-image --tool:svm-wasm -cp "$CP:$SCRATCH/web-classes" -H:ConfigurationFileDirectories=config/minimal \
  -o $SCRATCH/web/wasm-main aprvj.web.WebMain
node --experimental-wasm-exnref $SCRATCH/web/wasm-main.js "<receipt base64>" "<jws>" "<jws-root.der base64>" 200
```

The Rust library is `rust/ffi` built with `cargo build --release`, unchanged.
The CE build is `GRAALVM_HOME=<CE 25.0.2> ./build.sh config/minimal libaprvj_ce`.
